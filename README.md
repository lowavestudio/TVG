# ОФК — Допуск к подарку
### Интерактивное поздравление с днём рождения Генерального директора ОФК Тетеревенкова Виталия Геннадьевича

Персональный интерактивный подарок от команды **Озёрской фурнитурной компании (ОФК)**: квест-приключение в премиальном технологичном стиле Apple & ОФК, с уважительным корпоративным юмором, мини-играми на знание компании и музыкальным сюрпризом в финале.

---

## 🧭 Сценарий приключения

1. **Персональный вход**
   - Заголовок: *«Виталий Геннадьевич, сегодня всё работает на вас»*.
   - Интерактивный кейс специальной поставки с тремя заблокированными секциями.
   - Деликатный переключатель звука (по умолчанию выключен).
   - Кнопка *«Принять поставку»*.

2. **Испытание I: «Так говорит директор»**
   - 3 вопроса по крылатым фразам и принципам руководителя.
   - Неправильный ответ вызывает доброжелательную реакцию и позволяет сразу повторить выбор.
   - Правильный ответ сопровождается тактильной анимацией успеха.
   - **Награда:** 1-й ключ — **«Авторитет»**.

3. **Испытание II: «Идеальный механизм»**
   - Мини-игра по реальному ассортименту ОФК:
     - *Петля мебельная 110° с доводчиком* (Soft-Close)
     - *Направляющие скрытого монтажа* (Tandem Glide)
     - *Ручка-профиль TVG Wood* (Массив благородного дуба)
   - Управление: клик на деталь + клик на посадочный паз, Drag & Drop или клавиатура.
   - После полной сборки механизм оживает с кинетической анимацией.
   - Подпись: *«Когда всё на своих местах — чувствуется руководство»*.
   - **Награда:** 2-й ключ — **«Точность»**.

4. **Испытание III: «Решение генерального»**
   - 3 ситуации из жизни компании (рекорд склада 2 500 м² в Озёрске, спрос на TVG Wood на Ozon/WB, секретная поставка).
   - Нет проигрыша: каждый выбор раскрывает лидерский стиль и вызывает тёплую реакцию команды.
   - **Награда:** 3-й ключ — **«Команда»**.

> **Полномочия директора:** В каждом испытании доступна ненавязчивая кнопка *«Полномочия директора: пропустить»*, мгновенно засчитывающая этап.

5. **Открытие подарка**
   - Все 3 ключа занимают свои места.
   - Статус: *«Допуск подтверждён. От всей команды ОФК»*.
   - Визуальный переход: раскрытие кейса, золотистый свет, салют конфетти и посвящение:
     *«Есть вещи, которые не помещаются в рабочие письма. Поэтому мы сделали для вас песню»*.

6. **Песня и поздравление**
   - Персональная поздравительная карточка Виталия Геннадьевича с монограммой бренда **TVG**.
   - Полнофункциональный аудиоплеер с песней **«ТВГ»** (`tvg-song.mp3`):
     - Воспроизведение и пауза (запуск по явному клику пользователя);
     - Перемотка и таймкоды;
     - Повтор и скачивание аудиофайла;
     - Раскрывающийся текст песни;
     - **Реальный анализатор спектра частот** через Web Audio API (`AnalyserNode`), реагирующий на играющий звук.
   - Лента искренних поздравлений от подразделений:
     - Складской комплекс Озёрск (2 500 м²);
     - Отдел оптовых продаж (Озёрск — Москва);
     - Направление маркетплейсов (Ozon и Wildberries);
     - Мастера линейки TVG Wood;
     - Логистика и автопарк;
     - Финансовый и IT-отдел.
   - Возможность пройти квест заново при сохранении разблокированного доступа.

## 🚀 Быстрый запуск локально

Проект разработан на **React 19 + TypeScript + Vite**.

```bash
# 1. Перейдите в каталог проекта
cd ofk-birthday-quest

# 2. Установите зависимости
npm install

# 3. Запустите локальный сервер разработки
npm run dev
```

Откройте появившийся локальный адрес (обычно `http://localhost:5173/`).

Собрать релизную версию:
```bash
npm run build
npm run preview
```

## 🛠️ Замена материалов и настройка (`questConfig.ts`)

Все тексты, фразы, списки отделов, цвета и медиа вынесены в единый типизированный файл:
👉 `src/config/questConfig.ts`

### 1. Как добавить / заменить фото директора:
1. Поместите фото в формате `.jpg` или `.png` в папку `public/assets/director.jpg`.
2. В файле `src/config/questConfig.ts` в блоке `person` укажите:
   ```ts
   photoUrl: './assets/director.jpg',
   ```
*(Если фото нет, сайт автоматически показывает представительскую монограмму «TVG» с золотым тиснением и фирменным стилем).*

### 2. Главная песня:
Файл песни уже интегрирован в проект по пути `public/audio/tvg-song.mp3` (из предоставленного трека `ТВГ.mp3`).
В конфигурации `src/config/questConfig.ts`:
```ts
audio: {
  songUrl: './audio/tvg-song.mp3',
  title: 'Песня в честь ТВГ',
  artist: 'Команда ОФК (Озёрск — Москва)',
  ...
}
```

### 3. Настройка цитат и шуток:
В секциях `trial1_quotes` и `trial3_decisions` в `src/config/questConfig.ts` вы можете изменить любой вопрос, фразу или комментарий за считанные секунды без правок React-кода.

## 🌐 Размещение на GitHub Pages (Бесплатно)

В проект уже включена конфигурация относительных путей (`base: './'`) и официальный workflow автоматической сборки.

### Пошаговая инструкция:

1. **Создайте репозиторий на GitHub:**
   - Назовите его, например, `ofk-birthday` или `teterenkov-birthday`.
   - Репозиторий может быть публичным.

2. **Инициализируйте git и загрузите проект:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit: OFK birthday quest"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/ofk-birthday.git
   git push -u origin main
   ```

3. **Включите GitHub Pages в настройках репозитория:**
   - Перейдите в репозиторий на GitHub ➔ **Settings** ➔ вкладка **Pages** (слева).
   - В блоке **Build and deployment** ➔ **Source** выберите **GitHub Actions**.

4. **Готово!**
   При каждом `git push` в ветку `main` (или при ручном запуске во вкладке **Actions**) сайт автоматически собирается и публикуется.
   Адрес страницы будет вида:
   `https://ВАШ_ЛОГИН.github.io/ofk-birthday/`

> **Обратите внимание на безопасность материалов:**
> Квест скрывает подарок и песню только на уровне интерфейса для создания атмосферы сюрприза. На любом публичном статическом сайте (GitHub Pages, Vercel, Netlify) прямые ссылки на аудиофайлы в `public/` технически доступны в коде страницы. Если сюрприз должен оставаться в тайне до момента вручения, отправляйте ссылку имениннику непосредственно в день праздника.

## 🖥️ Размещение на собственном веб-сервере

Выполните команду:
```bash
npm run build
```
В каталоге `dist` будет сформирован готовый набор статических файлов:
- `dist/index.html`
- `dist/assets/`
- `dist/audio/`
- `dist/favicon.svg`

Просто скопируйте всё содержимое папки `dist` на любой веб-сервер (Nginx, Apache, Beget, Timeweb, Reg.ru). Сайт работает автономно без серверных баз данных или Node.js на хостинге.
