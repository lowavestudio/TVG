# ТЕТЕРЕВЕНКОВ SIMULATOR: ГЕНЕРАЛЬНЫЙ УРОВЕНЬ 👑
### Интерактивный сайт-поздравление с днём рождения для генерального директора ОФК Тетеревенкова Виталия Геннадьевича

> **«Виталий Геннадьевич. Доступ к финансовым потокам разрешён»**

---

## 💎 О проекте

Сайт разработан как персональный премиальный интерактивный подарок с юмором, аркадной мини-игрой, реальным видео коллектива и музыкальным рэп-финалом в стиле King of Trap.

Сайт состоит из 3 последовательных блоков:
1. **Шуточная авторизация в терминале генерального директора**:
   - Логотип ОФК, секретный терминал `ROOT_ACCESS`.
   - 4 контрольных юмористических вопроса с моментальными реакциями системы (проверка генеральной логики на 146%).
   - Финальный вердикт: «ЛИЧНОСТЬ ПОДТВЕРЖДЕНА. Уровень полномочий: ГЕНЕРАЛЬНЫЙ. Доступ к финансовым потокам разрешён».
2. **Аркадная мини-игра «Поймай деньги»**:
   - Игровой аватар Виталия Геннадьевича на базе реального фото в золотом сейфе-каре ОФК.
   - Механика ловли: мешки с деньгами (цель: 5 мешков 💰), пачки рублей и золотые монеты.
   - Препятствия: штрафы маркетплейсов (WB, Ozon), возвраты и комиссии с замедлением и звуковыми эффектами (проиграть нельзя, игра длится до триумфа).
   - Управление: стрелки влево/вправо, клавиши A/D, свайп/перетаскивание пальцем на экране или крупные экранные кнопки.
   - Автоматический переход к победному экрану и золотому фейерверку.
3. **Видео, подарок и музыкальный финал**:
   - **Этап A**: Анонс секретного финансового актива ОФК.
   - **Этап B**: Настоящее видео команды ОФК (бросают лепестки роз в фирменных футболках WB и OZON под логотипом компании).
   - **Этап C**: Анимация открытия сейфа с официальной обложкой трека **«TVG — KING OF TRAP»**.
   - **Этап D**: Интерактивный аудиоплеер с синхронизированным караоке (подсветка активной строки, прокрутка, перемотка по таймлайну, регулировка калибровки).
   - **Этап E**: Финальное душевное поздравление от коллектива с кнопкой «Просмотреть ещё раз».


   ```bash
   npm run dev
   ```
3. Откройте появившуюся ссылку в браузере (обычно `http://localhost:3000` или `http://localhost:5173`).

## 📦 Сборка и публикация на Vercel

Проект полностью готов для публикации на **Vercel** или любом статическом хостинге (GitHub Pages, Netlify, Render):

### Способ 1: Через Vercel CLI
```bash
npm i -g vercel
vercel
```

### Способ 2: Через интерфейс vercel.com
1. Создайте репозиторий на GitHub и загрузите проект.
2. Авторизуйтесь на [vercel.com](https://vercel.com).
3. Нажмите **Add New...** -> **Project** и импортируйте ваш репозиторий.
4. Настройки сборки определяются автоматически:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
5. Нажмите **Deploy** — через 30 секунд сайт будет доступен в интернете по красивой ссылке!
